# Custom Development Model (Phase 16 §30–41, §89–99)

Positioning: RESEARCH-DRIVEN EA DEVELOPMENT — "We do not stop at coding. We
test the logic." The differentiator is the TYO LAB evidence pipeline.

## Types (§36, §93)
BASIC (spec final) · RESEARCH (logic research included) · ADVANCED QUANT
(OOS / WF / MC / Shadow under Evidence-by-Design) · AI TRADING SYSTEM
(AI / MCP / data pipeline). Pricing: CONTACT FOR QUOTE — no fixed list.

## Flow
Consultation → Strategy design → Specification → Development → Backtest →
Revision → Delivery. Advanced track adds Research → OOS → Walk-forward →
Monte Carlo → Shadow forward (the Phase 14 / 13.5 engines).

## Request model (backend)
```
requestId, type (development | modification), name, company?, email, country,
platform (MT4 | MT5 | both), symbol, timeframe, strategyType, existingSource
(none | mq | ex | spec), desiredFeatures, budgetRange?, deadline?, message,
ndaRequested, createdAt, status (NEW | REVIEWING | QUOTED | ACCEPTED | DECLINED)
```
File upload arrives with the inquiry backend (§38).

## Rules
No fixed prices (§94) · no invented clients or testimonials (§41, §128) ·
case studies only from the public Research Log once marked showable ·
white-label hidden until offered (§96) · NDA available (§97) · source
ownership / commercial rights / redistribution rights defined per contract (§98).
